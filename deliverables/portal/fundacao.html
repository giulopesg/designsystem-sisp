Fundação

Os tokens de design são os valores fundamentais que garantem consistência visual em todo o sistema. Organizados em dois níveis — primitivos (valores brutos da paleta) e semânticos (intenção que os componentes consomem) — eles permitem theming por cliente sem alterar componentes.

Iconografia

Font Awesome Free — O DS SISP usa Font Awesome Free como biblioteca de ícones. Os ícones são consumidos via classes CSS (fa-solid, fa-regular) e dimensionados em 5 tamanhos padronizados (XS 16px, SM 20px, MD 24px, LG 28px, XL 32px).

Regras de uso

  • Usar sempre os tamanhos padronizados do token system (XS–XL)
  • Manter consistência: mesmo contexto = mesmo tamanho de ícone
  • Ícones decorativos devem ter aria-hidden="true"
  • Ícones informativos precisam de label acessível (sr-only ou aria-label)
