Button

Base Component Aprovado

Botão de ação para interações primárias, secundárias e terciárias. Suporta ícones, estados de loading e variantes de tamanho. É o componente mais crítico para identidade visual do DS.

Propriedades

API do componente Angular. Todas as props são passadas via [sispLibButtonConfig].

Prop Tipo Obrigatório Padrão Descrição
type 'primary' | 'secondary' | 'tertiary' | 'danger' Não 'primary' Variante visual — hierarquia de ação
label string Sim — Texto do botão. Verbo no imperativo: "Consultar", "Salvar"
icon string Não — Classe Font Awesome (ex: fa-solid fa-search)
size 'sm' | 'md' | 'lg' Não 'md' Tamanho: SM (32px), MD (40px), LG (48px)
disabled boolean Não false Desabilita interação — opacidade 0.5, cursor not-allowed
loading boolean Não false Substitui ícone por spinner, bloqueia clique, mantém largura
fullWidth boolean Não false Botão ocupa 100% da largura do container

Exemplo Angular

Integração com o componente sisp-lib-button. Cole no template do seu componente.

HTML 
<!-- Botão primário com ícone -->
<sisp-lib-button
  [sispLibButtonConfig]="btnConsultar">
</sisp-lib-button>

<!-- Botão danger para exclusão -->
<sisp-lib-button
  [sispLibButtonConfig]="btnExcluir">
</sisp-lib-button>
TypeScript 
btnConsultar: SispLibButtonConfig = {
  type: 'primary',
  label: 'Consultar',
  icon: 'fa-solid fa-search',
  size: 'md'
};

btnExcluir: SispLibButtonConfig = {
  type: 'danger',
  label: 'Excluir',
  icon: 'fa-solid fa-trash',
  size: 'md'
};

Acessibilidade

Critérios WCAG AA implementados neste componente. Todos verificados e aprovados.

  • Contraste mínimo 4.5:1 entre texto e fundo — Primary: 5.2:1, Danger: 7.8:1 WCAG 1.4.3
  • Foco visível com ring de 2px ao navegar por teclado — nunca removido WCAG 2.4.7
  • role="button" e aria-label quando não há texto visível (icon-only) WCAG 4.1.2
  • Suporta ativação via Enter e Space WCAG 2.1.1
  • Estado disabled comunica via aria-disabled="true" — mantém focável para screen reader WCAG 4.1.2
  • Estado loading comunica via aria-busy="true" e texto de status ("Salvando...") WCAG 4.1.3
